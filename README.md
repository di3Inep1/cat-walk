# 猫的第九次散步

无需安装依赖的本地 Canvas 横版游戏，三章共 9 个长关卡：林间散步、潮汐码头、月夜旧磨坊。第三章串联 3-1「霜夜磨坊」、3-2「运粮走廊」、3-3「阁楼归途」，完整改造见 MILL-REDESIGN.md。原 24 小关已整理成连续段落，最新合并安排见 LONG-LEVELS.md；旧规划保留供参考。

直接打开 index.html 即可离线游玩。也可在此目录执行：

    node serve.cjs

然后访问 http://127.0.0.1:4173/ 。关闭服务器终端会停止服务。

## 手机试玩

手机与电脑连接同一局域网。在此目录执行：

    node serve.cjs --lan

手机浏览器打开终端列出的实际以太网或 Wi-Fi 地址（不要选 VPN 或虚拟网卡地址，也不要使用 localhost）。若 4173 已被旧服务占用，先停止旧服务，或在 PowerShell 中设置 $env:PORT='4174' 后执行上述命令。仅提供游戏页面、脚本、样式与指定美术素材，不提供源码目录列表。

推荐横屏：左手方向，右手跳跃；可同时按住。轻触小跳，长按大跳。重试按钮从最近路灯复活。全屏包含操作按钮；不支持原生全屏时使用页面展开模式。切换应用或旋转屏幕会暂停，点击“继续散步”恢复。

本地联机试玩时，电脑需保持开机和服务运行。也可直接访问下方 GitHub Pages 线上链接，使用手机独立游玩。

操作：A/D 或左右键移动；空格/W/上键跳跃（松开缩短跳跃）；R 从路灯重试；Esc 暂停。触屏按钮在触屏设备显示。

第一关只教学跳跃与一块裂纹板：桥板在踩上 1.15 秒后消失，下方小路可以补救；后续关卡按设计使用 0.65–0.9 秒。桥板死亡后复原。红色荆棘与飞果会造成死亡。路灯需实际落地后激活。鱼干为可选收集，不影响通关。

点击“选关”可切换三章，每章三个长关。每章首关直接开放，章内完成一关解锁下一关，可重玩已解锁关卡。原短关和旧长关存档兼容，不覆盖旧短关存档。

每关分别自动保存最近路灯、本次计时、跌倒次数与已拾取鱼干。刷新后点击“从路灯继续”，或在选关中返回未完成的关卡，即可从路灯继续。暂停菜单可重新开始当前关卡。这轮风、冰面与传送带路线更新会把上一版存档接回对应路灯，保留本次计时、跌倒、鱼干与解锁；因路线长度变化，受影响关卡的旧最佳成绩重新记录。更早且无法识别的地图暂存仍回到起点。进度与成绩保存在当前浏览器。

鱼干收集按关累计去重。每次通关独立记录最佳时间和最少跌倒次数，结算及选关卡片显示成绩。重新开始会清空本次进度，累计收集和最佳成绩仍保留。石阶与果园提供安全木道与两段可选棚顶支路，棚顶鱼干共两条，支路可以回到主路。

地图长约 2680–4290 世界单位，通常使用近景，机关长跳前平滑拉远以预览落点。内部段落间连续通行，多个路灯记录复活位置，底部细条显示当前路程。3-2 磨坊样板在选关中直接开放，包含 15 个主要平台、4 盏路灯和 3 条鱼干，分别介绍顺向与逆向运粮带；通关后照常解锁 3-3。

第二章：顺风逐渐增加空中位移，逆风缩短跳程；2-1 的两处长缺口必须借风，2-3 把高跳软垫与顺风长跳组合。第三章：浅蓝冰面低摩擦并可滑行蓄速，起跳保留速度，按反方向刹车；帆布带的顺逆向速度会带入起跳并逐渐衰减。3-1 先练霜面长跳、再练近落点收速；3-2 用顺向长跳、逆向短跳、顺向长跳依次展开；3-3 复用两种机关。七处长缺口在关闭对应机关后无法用普通长跳通过，同时保留多处可行起跳位置。均使用原来的方向键与跳跃键，无需新按键。设计和参数见 MECHANICS-DESIGN.md。

线上试玩：https://di3inep1.github.io/cat-walk/ 。源码仓库：https://github.com/di3Inep1/cat-walk 。第一关的设计预算与真人试玩记录见 PLAYTEST.md；真人试玩尚未完成。

三章使用 imagegen 原创绘本素材。森林包含视差背景、草地、裂纹木桥、棚顶与树洞。码头包含午后海港背景、木栈桥、蓝色弹性垫、货箱、帆船、开敞货仓、吊架与灯塔。磨坊包含霜夜远景、石檐、薄霜、支柱、室内木廊、运粮设备、旧木梁、铜铃、门拱与暖窗小屋。猫猫动作、路灯、鱼干与提示牌用于全部章节。提示牌固定在场景中，猫猫穿过时平滑淡出，离开后恢复。素材保存在 assets，实际提示词、尺寸与使用范围见 assets/ART-DIRECTION.md。

首次只加载共用素材与当前章节，切换章节时加载缺少的素材，后续重玩使用缓存。加载期间显示“正在翻开绘本”，计时与角色暂停，图片缺失时可使用原有绘制继续游玩。角色脚底与平台顶面按游戏世界坐标对齐。音效由 Web Audio 合成，不包含背景音乐。

声音包含草地、木板、屋瓦、冰面、帆布和软垫的材料脚步与落地声，以及收集、路灯、塌板、失败、通关提示。森林、海港、屋顶、磨坊使用轻量环境声；磨坊木轮的声音随距离变化。声音仅在手势后启动，静音、暂停、切到后台或选关会停止环境声与音效，恢复游玩后继续。素材与音效均不依赖第三方音频下载。

3-2 使用独立手绘磨坊室内：低梁门厅、高窗机械间、斜梁阁楼、暖光出口依次展开，分别使用不同的背景构图，房间之间由实木立柱衔接。旧木廊、帆布运粮机、木支架、粮斗、传动木轮和铜铃独立绘制。此关只加载共用素材与六张磨坊图片；机关前后设置稳定木台，中央帆布沿实际推送方向移动。背景图片合计约 897 KiB，本轮机关布局更新同步移动房间分界。完整改造安排见 MILL-REDESIGN.md，实际生成提示词见 assets/ART-DIRECTION.md。

磨坊粮斗位于木廊下方的后景作业区，支架与设备降低对比，主路线台面保留清楚的边缘。猫脚接触阴影根据真实台面位置绘制，不投向缺口或已塌平台。猫猫共用动作扩展图集包含眨眼、刹车、回望、抬头、落地、放松；跑步节奏跟随速度，所有动作保持原有碰撞与起跳响应。

3-2「运粮走廊」另有光影样板：高窗月光与浮尘、近处木柱视差、沿帆布移动并落入收粮盘的谷粒、路灯与出口暖光。木台落地扬起少量木屑，帆布落地则是轻粉尘。全部新增动画随暂停冻结，不改变路线、跳跃手感或存档。

共用路灯的未激活玻璃保持暗色，激活后约 0.24 秒内亮起，短暂增亮后稳定。暖光对准实际灯芯，并在真实台面上形成柔和光斑，点亮时有少量上升光屑。暂停冻结过渡，恢复存档直接保持已点亮状态。

第三章三关统一采用参考 HTML 的光照分层思路：墙面有低强度暖色反光，猫、石台、木廊和冰面随灯源位置受光，猫脚边有背离灯源的柔和投影；未受光部分略偏冷。冰面落地与刹车产生小冰屑，普通石台产生少量灰尘，木廊与帆布分别产生木屑与轻粉尘。继续保留原有手绘素材与 2D 玩法。

森林的摆动红果、麻绳、雨棚与码头风向标已补齐手绘素材：红果在原有碰撞位置摆动，雨棚为透明开口的木构小棚，风向标使用条纹亚麻布风筒。相关素材只在实际使用它们的关卡加载，红果的伤害半径、运动速度、平台和路灯位置保持原样。

3-1 从开阔霜夜进入近处磨坊石墙，经过背风拱廊和暖色门厅；薄霜段之间留出干燥石台。3-3 从露天外廊进入有圆窗和斜梁的阁楼，以连续手绘斜屋檐、有厚度的石墙转角和木廊构成建筑剖面，入口与出口没有独立石门。屋檐下的暗廊让背墙逐步由室外石墙过渡到室内，猫、路灯和真实平台保持清楚。室内背景和窗光裁切在真实屋顶下方，屋顶上方延续室外夜空。帆布传送机完全位于室内，穿出阁楼后经过裂纹旧木桥，沿安静山谷回到暖窗。新增庭院与归途两张背景约 587 KiB，另有仅 3-3 使用的透明屋顶素材。室外霜尘在进入阁楼后停止，室内月光与浮尘对准实际窗户；室内外声音随位置切换。恢复路灯存档时显示所在段落的提示。第三章只加载各关实际使用的磨坊图片，旧城市屋顶与滑动瓦檐保留为历史素材，不再参与加载。
